Loci2D Love2D SDK

Guia rápido de integração para o seu primeiro protótipo cliente-servidor.

Passo 1

Instalação

Para usar o SDK no seu projeto, você precisa copiar os arquivos do SDK para dentro da pasta do seu jogo Love2D.

  1. Crie uma pasta chamada sdks/love2d (ou algo similar) dentro do seu projeto.
  2. Copie o arquivo loci_client.lua e a pasta lib/ para dentro dela.
  3. A pasta lib/ deve conter os arquivos pb.lua, protoc.lua e game_packets.proto.
Passo 2

Importação e Conexão

No seu arquivo main.lua, importe o SDK, ajuste o package.path se necessário, e conecte-se ao servidor dentro da função love.load.

-- Ajuste o caminho se você colocou o SDK em subpastas
package.path = package.path .. ";sdks/love2d/?.lua"
local loci = require("loci_client")

function love.load()
    -- (IP do Servidor, Porta, Nome do Jogador, Caminho relativo para a pasta lib/)
    loci.connect("127.0.0.1", 8080, "MeuJogador", "sdks/love2d/lib/")
end

Nota importante: O quarto parâmetro de loci.connect é fundamental! Ele diz ao SDK onde encontrar os arquivos internos do Protobuf (o game_packets.proto). Passe o caminho relativo da pasta onde você roda o seu jogo até chegar na pasta lib/ do SDK, terminando com uma barra /.

Passo 3

O Ciclo do Jogo (Game Loop)

O SDK do Loci2D processa os pacotes de rede recebidos de forma assíncrona. Você deve chamar a função loci.update(dt) a cada quadro.

function love.update(dt)
    -- Processa a rede e sincroniza o mundo
    loci.update(dt)
end
Passo 4

Movimentação do Personagem

A melhor forma de enviar intenções de movimento é lendo o estado atual do teclado dentro do seu love.update(dt) e avisando ao SDK quando a direção muda.

local last_dx, last_dy = 0, 0

function love.update(dt)
    loci.update(dt)
    
    local dx, dy = 0, 0
    if love.keyboard.isDown("w") then dy = -1 end
    if love.keyboard.isDown("s") then dy = 1 end
    if love.keyboard.isDown("a") then dx = -1 end
    if love.keyboard.isDown("d") then dx = 1 end
    
    -- Enviar o pacote apenas se a direção mudou
    if dx ~= last_dx or dy ~= last_dy then
        last_dx, last_dy = dx, dy
        loci.send_move(dx, dy)
    end
end
Passo 5

Desenhando o Mundo Autorizado

O servidor é a fonte da verdade! Desenhe as entidades lendo a lista de entidades providenciada pelo SDK no love.draw().

function love.draw()
    local entities = loci.get_entities()
    
    for _, entity in ipairs(entities) do
        if entity.id == loci.my_entity_id then
            love.graphics.setColor(0, 0.5, 1) -- Você em azul
        else
            love.graphics.setColor(1, 0, 0) -- Outros em vermelho
        end
        
        love.graphics.circle("fill", entity.x, entity.y, 16)
        
        -- Lendo propriedades customizadas vindas do servidor
        local hp = entity.properties and entity.properties["hp"]
        if hp then
            love.graphics.print("HP: " .. hp, entity.x - 20, entity.y - 24)
        end
    end
end

Referência da API do Loci2D

Funções Principais

Função Descrição
loci.connect(ip, port, name, lib_path) Inicia a conexão UDP e carrega o schema do Protobuf.
loci.update(dt) Processa pacotes recebidos, faz o ping e interpola posições.
loci.disconnect(reason) Envia a intenção de desconexão e fecha o socket.
loci.send_move(dir_x, dir_y) Envia intenção de movimento. (1, 0), (-1, -1), etc.
loci.send_action(ability_id, x, y) Envia intenção de cast de magia ou ataque para o mundo (X, Y).
loci.get_entities() Retorna a lista de todas as entidades renderizáveis.
loci.get_my_entity() Retorna a tabela da sua própria entidade, útil para câmeras.

Callbacks (Eventos)

Você pode sobrescrever essas funções no seu main.lua para reagir aos eventos do servidor:

Callback Acionado quando...
loci.on_entity_spawned = function(ent) Uma nova entidade surge na sua visão do servidor.
loci.on_entity_despawned = function(id) Uma entidade é destruída ou sai do seu campo de visão.
loci.on_property_changed = function(ent, key, old, new) O servidor altera uma propriedade visual (ex: "hp", "team").
loci.on_intent_rejected = function(reason) O servidor recusa uma ação sua (ex: tentando usar magia em cooldown).
