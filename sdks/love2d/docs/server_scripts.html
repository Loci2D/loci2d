Loci2D Server Scripts

Guia para criação de regras, mecânicas e habilidades no servidor em Lua.

Estrutura

O que é o Script do Servidor?

Enquanto o Love2D processa os gráficos e a entrada do jogador, o servidor em Rust roda um ambiente isolado em Lua que dita as regras do jogo. A autoridade máxima é sempre do servidor!

Todos os scripts ficam na pasta scripts/nome_da_arena/main.lua. Quando o servidor sobe, ele lê esse arquivo para injetar vida nas mecânicas.

Passo 1

Ouvindo os Jogadores (Callbacks)

No seu main.lua do servidor, você deve declarar as seguintes funções globais. A engine em Rust vai chamá-las automaticamente quando os eventos acontecerem:

-- Chamado quando um jogador entra na sala
function on_player_join(entity_id)
    Loci.Log.info("Jogador " .. entity_id .. " entrou!")
    Loci.Commands.set_property(entity_id, "hp", "100")
end

-- Chamado quando um jogador tenta se mover (WASD do cliente)
function on_move_intent(entity_id, dir_x, dir_y)
    local SPEED = 5.0
    -- Aplica a velocidade na entidade
    Loci.Commands.set_velocity(entity_id, {x = dir_x * SPEED, y = dir_y * SPEED})
    return true -- Retorna true para aceitar o comando
end

-- Chamado quando o jogador desconecta
function on_player_leave(entity_id)
    Loci.Commands.destroy_entity(entity_id)
end
Passo 2

Criando Habilidades (Skills)

Quando o cliente chama loci.send_action(ability_id, x, y), o servidor recebe isso através da função on_action. É aqui que a mágica acontece!

💡 Dica de Input: O servidor não sabe se o jogador clicou com o mouse, apertou a barra de espaço, ou usou um controle de videogame! O cliente fica encarregado de mapear os botões e chamar a função enviando apenas o ability_id. O servidor recebe apenas a intenção ("Usar habilidade 1 nas coordenadas X, Y"). 

function on_action(entity_id, ability_id, aim_x, aim_y)
    if ability_id == 1 then
        -- Habilidade 1: Tiro de Fogo
        local fireball = {
            blueprint = "Fireball",
            position = {x = aim_x, y = aim_y},
            entity_type = "Projectile",
            properties = { damage = "20" }
        }
        Loci.Commands.spawn_entity(fireball)
        return true
    end
    
    -- Retorne false e uma string para rejeitar e avisar o cliente
    return false, "Habilidade desconhecida ou em cooldown!"
end
API

Referência Loci.Commands

O módulo Loci.Commands é a ponte entre o seu script Lua e o motor de física do Rust.

Comando O que faz?
spawn_entity(params) Cria uma entidade. Recebe tabela: {blueprint, position={x,y}, entity_type, move_speed, radius, properties={}}
destroy_entity(id) Remove a entidade instantaneamente do jogo.
set_position(id, {x, y}) Teleporta a entidade para as coordenadas especificadas.
set_velocity(id, {x, y}) Aplica uma força de movimento (reseta na próxima intenção).
set_navigation_target(id, {x, y}) Ordena a entidade a andar automaticamente até o ponto (Pathfinding).
set_property(id, key, value) Altera uma propriedade (ex: "hp", "team"). Sincroniza com todos os clientes!
set_global(key, value) Seta uma propriedade global da partida (ex: "tempo", "pontuacao").
start_timer(timer_id, ticks) Cria um timer. Quando acabar, dispara on_timer_completed(timer_id).
Debug

Logs no Console

Para investigar o que está acontecendo no servidor, sempre use os métodos da tabela Loci.Log. Os prints nativos do Lua podem não aparecer no console do Rust de forma síncrona.

  • Loci.Log.info("Mensagem") - Verde no console.
  • Loci.Log.warn("Aviso") - Amarelo no console.
  • Loci.Log.error("Erro!") - Vermelho no console.
